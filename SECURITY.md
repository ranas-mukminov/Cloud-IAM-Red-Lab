# Security Policy

## Scope

This repository is a simulation lab. It contains no cloud account, no
credentials, and no connection to any cloud provider.

## Reporting a problem

Open an issue describing the file and the problem. Do not include real
account IDs, ARNs, credentials, or policy documents from a real cloud
account. If you believe a fictional example resembles a real policy,
say so in general terms only.

## Responsible use

Use the lab to learn IAM analysis and remediation. Do not apply its
techniques to a cloud account you do not own, and do not use it to
escalate privileges in any real environment, even a "test" account
that belongs to someone else.
